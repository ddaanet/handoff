# Changelog

One entry per design change, newest first. Each links the full write-time
record under `changelog/` — what the defect was, what was weighed, what was
believed at the time. Those files are never edited after the fact; a change
that reverses one heads the affected section with a superseding pointer.

[`design.md`](design.md) is the other half: present tense, current truth,
rewritten rather than annotated when a decision is reversed.

- [2026-07-31 — The pointer directory sweeps itself](changelog/2026-07-31-pointer-lifecycle.md) — the two items the drift change left open: the `write-guard.sh` rc 2 rewording rested on a file that hook has not guarded since FR4, and the session-keyed pointer and drift marker now expire, swept by their own producer at the next session start rather than by a `SessionEnd` that an abnormal end never fires
- [2026-07-31 — The session root stops drifting silently](changelog/2026-07-31-session-root-drift.md) — a cwd that leaves the launch repo split the writer from the readers in silence: the resolver now labels which branch it took, a session-keyed pointer file carries the root into the agent's Bash (where `CLAUDE_PROJECT_DIR` is unset and the old `$PWD` fallback was wrong in exactly that case), the checkpoint refuses without it, and `UserPromptSubmit` reports each drift episode once
- [2026-07-29 — Driven transitions](changelog/2026-07-29-driven-transitions.md) — the drive-the-TUI half splits out of `precompact` into `compact-continue`, `handoff` gains the symmetric `handoff-continue`, and the armed transition stops being a singleton modelled as N files: one `.claude/autodrive` whose body names the kind, one walker instead of three watchers, and the rename's last pane-grep confirmation retired for a `custom-title` transcript entry
- [2026-07-29 — The approval clause renders as a block](changelog/2026-07-29-approval-clause-renders-as-a-block.md) — a clause owned by another plugin cannot be spliced mid-sentence, and the single-line test fixture is why the suite could not see it; the unset-key branch stops blaming the plugin and asks for the restart that actually recovers
- [2026-07-28 — Memory-approval wording is discovered from gitlore](changelog/2026-07-28-memory-approval-from-gitlore.md) — the approval-body wording was a fourth independent copy; gitlore now owns it as one file and advertises the path through a git-config key, the only gitlore-advertised key the checkpoint reads
- [2026-07-28 — Stop's systemMessage stops echoing the compact directive](changelog/2026-07-28-stop-systemmessage-no-echo.md) — the arming confirmation interpolated the full `/compact <directive>` that the watcher types into the pane moments later, so the user saw it twice
- [2026-07-27 — `{"content": null}` is a no-op, not "content supplied"](changelog/2026-07-27-content-null-is-a-no-op.md) — key-presence validation treated an explicit `null` as content, so the literal string `null` was written into the task file, silently, past schema validation; both validators short-circuit to a no-op instead
- [2026-07-27 — One channel, one writer](changelog/2026-07-27-one-channel-one-writer.md) — one `handoff-checkpoint` call replaces the wipe, three Write calls, the transcript-scraped activation predicate and both probes, with `PostToolUse(Bash)` doing the `git add -f` and tmux work the agent's sandbox forbids; content, not activation, decides absence
- [2026-07-26 — An orphaned ledger hijacks the handoff](changelog/2026-07-26-orphaned-ledger.md) — a hand-rolled file at SDD's pre-6.2.0 flat path suppressed `handoff-todo.md` in a session running no SDD at all; detection becomes liveness — current layout glob, identity first line, newest mtime — and stays read-only and fail-open
- [2026-07-25 — Commit awareness](changelog/2026-07-25-commit-awareness.md) — both skills answer one question, is a commit going to carry this session's memory, and the code owns everything downstream; withholding the trigger filename under `with-commit` is the mechanism that makes the standalone commit unreachable, where a prohibition would introduce what it forbids
- [2026-07-23 — Overflow deserves the same persistence](changelog/2026-07-23-overflow-deserves-persistence.md) — `handoff-todo.md` becomes tracked like the task file; neither reason for the exception survived, the gitlore pairing being about a moment both files share and the churn cost imported from where a per-commit approval gate charged for it
- [2026-07-22 — A directive must fit where in the turn it lands](changelog/2026-07-22-directive-fits-where-it-lands.md) — the todo-file suppression was a no-op for handoff, which reads it in the same turn as the writes and therefore always after the file exists; shared prompt text is shared only where the flows agree
- [2026-07-22 — The submit signal, a third time: confirm the compaction](changelog/2026-07-22-confirm-the-compaction.md) — a live 103-second compaction was reported as never submitted; line 1 stops asking "did the keystroke land?" and asks "did the compaction happen?", and the wider rule is that nothing asking whether an action took effect reads the pane again
- [2026-07-22 — The rename watcher joins the failure channel](changelog/2026-07-22-rename-watcher-failure-channel.md) — the failure-file retrofit had skipped the rename watcher, even while naming its composing-bail as the archetype of a silent exit; both its non-delivery paths now report, through the same consumer
- [2026-07-22 — A stale autocompact is one a later turn can see](changelog/2026-07-22-stale-autocompact.md) — `Stop` does not fire on Esc, so an armed-but-abandoned file outlives its turn and the next normal `Stop` fires it, days later and in another session; `UserPromptSubmit` is the exact discriminator, and it sweeps the file
- [2026-07-22 — A place for the todo list](changelog/2026-07-22-a-place-for-the-todo-list.md) — task lists were being crammed into `handoff-task.md` and tracked again in memory; `.claude/handoff-todo.md` holds the remainder and nothing else, and the design names no todo tool, because the harness's own is behind a server-side killswitch
- [2026-07-22 — The submit signal, again: `is_busy` false-fails a queued continuation](changelog/2026-07-22-submit-signal-queued-continuation.md) — the continuation fires while the session is still settling, so the submit is *queued*: the transcript records it at once, the spinner appears thirteen seconds later, and confirmation moves to the transcript
- [2026-07-21 — precompact resets the task file too](changelog/2026-07-21-precompact-resets-the-task-file.md) — the two skills were on different activation protocols; precompact authors the file from the conversation rather than from its prior contents, so nothing on disk is input to it, and the asymmetry only bought a stale frame surviving into the turn that rewrites it
- [2026-07-20 — Consolidation pass](changelog/2026-07-20-consolidation-pass.md) — three duplications factored into shared helpers (the path-scoped hook preamble, the setsid-else-nohup detach, the watcher scaffold), no behavior change; merging the three `PostToolUse(Write|Edit)` scripts was considered and declined
- [2026-07-20 — A detached watcher's failure has to become a file](changelog/2026-07-20-watcher-failure-becomes-a-file.md) — a clean live run says nothing about whether a dirty one would be noticed; watchers write a non-delivery reason to a file surfaced at the next `UserPromptSubmit`, most of all the line-1 recognition abort, which wipes the composer and leaves the pane looking untouched
- [2026-07-20 — One task file, two transitions](changelog/2026-07-20-one-task-file-two-transitions.md) — precompact was forbidden from writing the task file, so verbatim-critical content got crammed into the one-line continuation prompt; both skills now share `handoff-task.md`, and one `handoff_frame` helper serves both transitions
- [2026-07-20 — The settle gap and the submit signal](changelog/2026-07-20-settle-gap-and-submit-signal.md) — an Enter sent immediately after a long `send-keys -l` lands inside the TUI's paste window and is absorbed as a line break; the gap was load-bearing for *submission*, not just verification, and invisible until line 2 dropped the recognition readback
- [2026-07-20 — precompact drives the compaction](changelog/2026-07-20-precompact-drives-the-compaction.md) — precompact stops telling the user to run `/compact` and arms it, plus the prompt that resumes the work, continuation being intrinsic to compacting; the memory commit moves to a file-trigger IPC, all writes, sidestepping the sandbox and the auto-mode classifier
- [2026-07-19 — Mid-turn TUI input: the taxonomy](changelog/2026-07-19-mid-turn-tui-input-taxonomy.md) — a spike found four classes of mid-turn input, not one queue: prose, which the earlier design treated as the safe line, is injected into the running turn's next model call, so both typed lines move onto harness-authoritative hooks
- [2026-07-17 — Task frame drops the transcript and file list](changelog/2026-07-17-task-frame-drops-transcript.md) — the verbatim transcript manufactured false continuity, a fresh session narrating a prior one's work as its own; it, the file list and the whole pointer chain come out in one pass, a design that proved harmful removed whole rather than left as a scaffold
- [2026-07-12 — Session compaction](changelog/2026-07-12-session-compaction.md) — compaction enters scope as a transcript feature, a compact summary having passed every extractor filter and inlined multi-KB of stale summary into the frame; ships `/handoff:precompact` as a thin memory-flush skill and settles the handoff/gitlore plugin boundary against three proposed restructurings
- [2026-06-24 — Commit status excluded from the task frame](changelog/2026-06-24-commit-status-excluded.md) — git bookkeeping written at handoff time is falsified by the `/commit` that routinely follows, then lands in history and is re-injected stale; fixed by removing the slot from the template, not by adding a prohibition
- [2026-06-12 — gitlore-aware handoff](changelog/2026-06-12-gitlore-aware-handoff.md) — a read-only probe emits a memory directive on a dirty `gitlore-memory` submodule; it is a PATH-shimmed script rather than skill prose, so the skill body stays gitlore-free and the non-gitlore user never learns gitlore exists
- [2026-06-09 — Per-worktree handoff root](changelog/2026-06-09-per-worktree-handoff-root.md) — hooks anchor on the enclosing linked-worktree root derived from on-disk `.git` linkage, so a worktree session owns its own `.claude/`
- [2026-06-05 — Read-time assembly: pointer + bounded scrape](changelog/2026-06-05-read-time-assembly.md) — `handoff.md` is eliminated for an ephemeral frame assembled at read time; the scrape is cut at the last activation, because an unbounded one glues the frame to prompts typed *after* the handoff and resolves anaphora to the wrong thing, silently
- [2026-05-19 — Original design: activation, loading, extraction](changelog/2026-05-19-original-activation-and-loading.md) — `PostToolUse` extraction from an agent-authored template file, a generated `handoff.md`, a `SessionStart` loader and a transcript-scraping extractor; every entry above reworked it, and the surviving core is the agent-authored task file plus `SessionStart` injection
